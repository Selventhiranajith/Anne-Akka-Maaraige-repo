# 💍 திருமண அழைப்பிதழ் — Wedding Invitation

Sri Lankan Tamil Wedding Invitation Card
Built with **React + TypeScript + Vite + Tailwind CSS**

## 🚀 Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## 📦 Build for Production

```bash
npm run build
npm run preview
```

## 🛠 Tech Stack

- React 18 + TypeScript
- Vite 5
- Tailwind CSS 3
- Google Fonts: Noto Serif Tamil + Playfair Display
